# Корчма · Tavern Farkle

Середньовічна гра в кубики для браузера та мобільних телефонів.

- 3D-кубики з фізикою кидків, видом зверху й вибором залікових комбінацій.
- Чотири суперники з різними стратегіями та портретами або гра вдвох на одному пристрої.
- Ціль партії на вибір: 4 000, 6 000 або 8 000 очок.
- Анімації відкладання кубиків, очищення столу та нарахування очок.

## Локальний запуск

Потрібен Node.js 22.13 або новіший.

```sh
npm ci
npm run dev
```

## Перевірки

```sh
node --experimental-strip-types --test tests/game.test.ts tests/physics.test.ts
npx tsc --noEmit
npm run build
```

## Структура

- `app/page.tsx` — інтерфейс, керування ходами та поведінка корчмаря.
- `app/globals.css` — стилі й анімації інтерфейсу.
- `components/dice-table.tsx` — 3D-стіл і взаємодія з кубиками.
- `lib/game.ts` — правила підрахунку очок і стан гри.
- `lib/physics.ts` — фізична форма кубиків, кидки й зіткнення.
- `tests/` — перевірки правил і фізики.

React, TypeScript, Three.js, cannon-es, Tailwind CSS та Vinext.
Публікація налаштована через Sites; `.openai/hosting.json` містить прив’язку до поточного сайту.

## Випадковість звичайних кубиків

Кожен кидок використовує браузерний Web Crypto (`crypto.getRandomValues`).
Нумерована оболонка кубика отримує одну з 24 рівноймовірних кубічних орієнтацій перед кидком, незалежно від траєкторії фізичного тіла. Для будь-якої грані, на якій зупиниться фізичне тіло, кожне число опиняється зверху рівно у 4 з 24 орієнтацій. Відображення та підрахунок читають ту саму оболонку; її орієнтація не змінюється після кидка. Це усуває вплив можливої асиметрії фізичного розв’язувача на ймовірності чисел.

Стратегії ботів не мають доступу до генератора випадковості, фізики або майбутніх результатів. Серії вдалих чи невдалих кидків не коригуються.

Перевірки випадковості: `node --experimental-strip-types --test tests/random.test.ts`.
